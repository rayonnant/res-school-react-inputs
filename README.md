# React Auth Forms

Простая и переиспользуемая реализация компонентов авторизации Signin и Signup на React. Формы созданы в соответствии с техническим заданием: валидация, кастомный компонент Input, обработка submit и передача данных через props.

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/rayonnant/react-auth-forms
cd react-auth-forms

# Установить зависимости
npm install

# Development режим с автообновлением
npm run dev

# Проверка production-версии
npm run build
npm run preview
